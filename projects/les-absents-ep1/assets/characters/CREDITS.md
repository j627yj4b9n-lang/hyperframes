# Character models

Noé, Lina, la mère and le père are avatars from **Microsoft Rocketbox**
(https://github.com/microsoft/Microsoft-Rocketbox), released under the MIT License,
Copyright (c) Microsoft Corporation.

| Folder | Rocketbox avatar                     |
| ------ | ------------------------------------ |
| noe    | Male_Adult_10 (facial blendshapes)   |
| lina   | Female_Adult_12 (facial blendshapes) |
| mere   | Female_Adult_14 (facial blendshapes) |
| pere   | Male_Adult_03 (facial blendshapes)   |

Textures were converted from TGA to JPG/PNG at 1024 px. Clothing colours are tinted in `assets/scene.js`.
